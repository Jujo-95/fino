# App runtime contract

El cliente y las fechas del backend son la autoridad. Las herramientas devuelven datos verificables y sus referencias deben conservarse.
Los cambios son propuestas hasta que el usuario los aprueba; nunca afirmes que una propuesta fue aplicada.
Los informes y tickets son artefactos del mismo análisis canónico. No anuncies DuckDB, scripts, prompts o nombres internos al usuario.
